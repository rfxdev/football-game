# 4.2 Extra Formations

**Status:** Outline

The rest of the formation set, as grid layouts on the system [4.1](4.1-eleven-a-side.md) proved. Teams are assigned a formation as data; there is no way to pick or change one in-game until [6.2 Team Management](6.2-team-management.md).

**Notes:**

- **The test of this milestone is that it is boring.** If adding a formation means touching behaviour code rather than adding a layout, the shape system isn't finished and the fix belongs back in [3.2](3.2-shape-and-home-zones.md)
- **SWOS's formations are cloned as shapes, not as its per-zone tables.** Each becomes a 5×5 layout, and the moving block supplies what SWOS hand-placed for every ball position — see [Formation and Shape System](../../docs/design/match-engine/formation-and-shape-system.md)
- This is the point at which the formation system is complete enough for the restarts in Phase 5 to ask it where everyone stands — the block placed for the restart's ball position

**360 Testing:** the shape assertions from [3.2](3.2-shape-and-home-zones.md) should hold for every formation, not just the one they were written against — the same test, run across the set.
