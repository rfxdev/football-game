# 2.2 Two Attackers

**Status:** Outline

2v1 against the keeper: a second player on your own side, and therefore control switching between them for the first time.

**Notes:**

- **Switching is a control-scheme decision, not a detail of this drill.** The reference has no switch button — the action button is already committed to sliding, heading and shooting, so control passes automatically to whoever is closest to the ball and is reassigned continuously as play moves. That is a significant constraint on everything after, and it is decided here
- **Whether the auto-switch flaps between two similarly-distant players is an open question in the reference itself** — see the open question in [Match Mechanics](../../sources/swos/match-mechanics.md). If it flaps, the fix is hysteresis, and this is the milestone that finds out
- A teammate also makes passing judgeable for the first time. [1.2 Kicking](1.2-kicking.md) established the kick; this is the first time it has somewhere to arrive

**Attributes:** Passing's cone and maximum length, built at [1.2](1.2-kicking.md), are judgeable for the first time now there is a teammate to find.

**Sprites:** whatever marks the controlled player. With control reassigned continuously, it is the only way to see a switch happen — check how the reference marks it before drawing one.
