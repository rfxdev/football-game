# 5.5 Clock, Halves and Full Time

**Status:** Outline

The match as a whole having structure: a clock, two halves, half-time, full time, and a result that survives the break.

**Notes:**

- **Half-time is why this sits apart from [5.2](5.2-out-of-play.md).** It is the match having structure, not a restart — the clock, periods and what survives the break are specified in [Match State Machine](../../docs/design/match-engine/match-state-machine.md)

**Testing:** this is where a headless, steppable match harness earns its keep, since there is finally a whole match to step. A testing concern distinct from the CPU vs CPU game mode itself, which remains an open architectural question in [CPU vs CPU Simulation](../../docs/design/tournament-and-career-mode/cpu-vs-cpu-simulation.md).

**360 Testing:** once a whole match can run headless, property runs over many seeded matches become viable: every match reaches full time without a crash or soft-lock, and goal rate and possession split fall within wide bounds — bounds, not exact targets. [3.2](3.2-shape-and-home-zones.md)'s goal-rate question, unanswerable when it was first asked, gets its first real consumer here.
