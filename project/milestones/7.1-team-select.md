# 7.1 Team Select

**Status:** Outline

A way into a match that isn't a debug scene: a menu, a friendly, both teams picked from [6.1 Squads](6.1-squads.md)' authored teams, and which one you control. One player against the CPU, one match at a time — no competitions, no two-player mode.

**Notes:**

- **The setup screen is where later choices go.** [7.2 Pitch Conditions](7.2-pitch-conditions.md) is the first; it should be another line on this screen, not a screen of its own
- **It leads into [6.2 Team Management](6.2-team-management.md)'s screen before kick-off**, which has been reached from a debug scene until now
- **SWOS's menus are a reference for flow, not layout.** Pixel-copied layouts are ruled out by [Licensing and IP](../../docs/decisions/licensing-and-ip.md)
- **Built for a controller**, like 6.2 — the d-pad moves between options, the action button picks
- **Two-player mode stays in [Ideas](../ideas.md).** Picking which team each pad controls is the part of it this screen would grow
