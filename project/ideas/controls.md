# Controls

Who plays, and on what.

- **Two-player mode** — couch co-op, a pad per player. The input seam that makes it cheap is in [On-the-Ball Mechanics](../../docs/design/match-engine/on-the-ball-mechanics.md#input-as-intent). Open: whether a pad is assigned by connection order or chosen on a join screen
- **Keyboard controls** — bound to the same actions as the pad, per [Technical Architecture and Stack](../../docs/decisions/architecture-and-stack.md)
