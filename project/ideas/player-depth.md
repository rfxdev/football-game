# Player Depth

Attribute depth comes before ability over time: how ability moves depends on which attributes there are, and on pace no longer deciding everything.

## Attribute Depth

- **Modernised attributes** — more than SWOS's seven, informed by [FM](../../sources/fm/player-attributes.md)
- **Attributes that drive AI** — mental attributes such as Positioning and Decisions shape how the 21 uncontrolled players behave, adding depth without touching single-button input
- **Fix speed dominance** — SWOS's [biggest balance fault](../../sources/swos/overview.md#weaknesses). More attributes do nothing if pace still decides everything
- **Summary ratings over detail** — FM-style star ratings or role suitability, so extra attributes don't slow the buy/don't-buy call
- **Generated players built attributes-first** — position and summary rating read off the attribute profile rather than rolled beside it, and hidden traits pull related attributes together, so every generated player has a recognisable shape

## Ability Over Time

- **Form** — short-term swings on top of fixed ability. A cheaper way to make selection matter than full progression
- **Ability that moves across a career** — progression and decline, which gives attributes a reason to change. Links [Career](career.md) and attributes. Championship Soccer did this on top of a SWOS clone
  - **Physical and technical age differently** — physical attributes peak early and fade first, technical ones climb for longer, so a veteran is signed for different reasons than a teenager
  - **Minutes build game sense** — mental attributes grow with match time rather than training, so playing a youngster trades points now for a better player later
  - **Soft ceilings, read by scouts** — growth slows towards a per-attribute talent level rather than stopping at one shared cap. Potential is a projection, read with error
- **Youth intake and retirement** — follows from progression. A squad that turns over, so a long save keeps producing new players worth finding
  - **Scarce stars** — a bounded number of exceptional youngsters per intake, each a coherent archetype, mostly at strong clubs but occasionally anywhere
