# football-game

A top-down 2D arcade football game, inspired by the mid-nineties classics of the genre. Fun over realism, single-button input, easy to pick up and difficult to master.

Start with [Game Vision and Design Goals](docs/design/game-vision-and-design-goals.md) for what the game is trying to be. [Contributing](CONTRIBUTING.md) covers what's accepted and on what terms.

The documentation is split by the question it answers:

- **[`docs/`](docs/README.md)** — what the game is: design intent, the player manual, and the decisions constraining both
- **[`ways-of-working/`](ways-of-working/README.md)** — how it gets built: testing loop, playtesting, tuning, builds
- **[`project/`](project/README.md)** — where it currently stands: the roadmap, the milestones, and what's being worked through
- **[`sources/`](sources/README.md)** — what the reference games do, in our own words: research notes, not their files
