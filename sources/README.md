# Sources

Research on games that inspire this one — what they do and why, in our own words. Not a place for their files.

Mechanics, rules, and systems are fair game to study and write up here. Sprites, tilesets, audio, fonts, manuals, or any other file taken from another game are not, whether extracted, scanned, or pasted in verbatim — see [Licensing and IP](../docs/decisions/licensing-and-ip.md) for the full line between the two. This folder isn't checked into that doc's third-party-asset intake process because nothing here ships with the game; it stays reference material for design work.

**When the manual and the code disagree, the code wins.** Manuals, interviews and memories describe a game loosely; the disassembly is what it does. Record both — what the code does, cited, and the description it corrects — so the correction isn't undone by the next person reading the manual. A disagreement is also a prompt to re-read the code: a reading can miss a path, and memory of play is evidence that it has.

Same goes for third-party text — manuals, forum posts, interview transcripts: we don't commit it. What does get committed here is written in our own words, with short quoted excerpts where useful.
